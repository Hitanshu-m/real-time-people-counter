# 👥 Real-Time People Counter

## 📌 About

This is a real-time **People Counting System** built using **Python and OpenCV**. The application uses a webcam to detect human faces and counts the number of people in the frame instantly. It draws bounding boxes around detected faces and displays the live count on the screen.

This project demonstrates basic computer vision techniques using Haar Cascade classifiers for real-time face detection and object counting.

---

## ⚙️ Tech Stack

* Python
* OpenCV
* Haar Cascade Classifier

---

## 🚀 Features

* Real-time face detection using webcam
* Live people counting system
* Bounding box visualization around faces
* Fast and lightweight processing
* Works in real-time video streams
* Simple and beginner-friendly implementation

---

## 🎯 How It Works

* Webcam captures live video feed
* Frames are converted to grayscale
* Haar Cascade detects faces in each frame
* Number of detected faces is counted
* Bounding boxes are drawn around faces
* Live count is displayed on screen
